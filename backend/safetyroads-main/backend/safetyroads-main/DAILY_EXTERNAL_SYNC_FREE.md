# Бесплатная ежедневная синхронизация

Отдельный Render Cron Job не нужен. `server.js` запускает проверку после старта и затем раз в час. Если прошло >= 24 часов с последней успешной синхронизации, запускается сборщик внешних проблем.

В PostgreSQL хранится состояние в `external_sync_state`. Advisory lock защищает от параллельных запусков.

Важно: на Render Free Web Service процесс может засыпать, поэтому это не гарантирует запуск ровно в одну и ту же минуту каждый день. При следующем пробуждении сервис догоняет пропущенную 24-часовую синхронизацию.
