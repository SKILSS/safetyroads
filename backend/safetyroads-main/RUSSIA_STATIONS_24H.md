# АЗС России: полный кэш + обновление раз в 24 часа

Эта версия SafetyRoad работает только с АЗС Российской Федерации.

- При первом запуске, если в PostgreSQL ещё нет российских АЗС, сервер сначала выполняет полный импорт `amenity=fuel` из OpenStreetMap/Overpass и только после этого начинает принимать запросы.
- После первого успешного импорта последующие запуски используют готовый PostgreSQL-кэш и не ждут повторного полного импорта.
- На стартовом масштабе карты приложение сразу запрашивает весь кэш `country=RU`, а MarkerCluster отрисовывает станции пакетно.
- Иностранные записи не выдаются API.
- Координаты и список АЗС обновляются не чаще одного раза в 24 часа.
- Цены запрашиваются из Интернета автоматически раз в 24 часа. Если доступен станционный провайдер, его точные цены имеют приоритет. Без такого провайдера используется публичный интернет-фид «Ехай»; его брендовые/региональные значения помечаются как `brand_median`/`region_median`, то есть это ориентир, а не гарантированная цена конкретной колонки.
- Ручные цены (`manual`) не затираются автоматической синхронизацией.
- Все автоматические ценовые обновления ограничены `country_code='RU'`.

## Важно про «все АЗС»

«Все» означает все станции, которые OpenStreetMap содержит как `amenity=fuel` на момент синхронизации. Это не государственный реестр, поэтому станция, которой нет в OSM, автоматически появиться не сможет.

## Первый запуск на Railway/Render

Нужна PostgreSQL база и переменная `DATABASE_URL`.

По умолчанию первая загрузка российских АЗС выполняется до `app.listen()`. Если провайдер Overpass временно недоступен, сервер всё равно запускается, а фоновый планировщик повторит синхронизацию позже.

Если необходимо принудительно не задерживать старт, можно задать:

```text
STATIONS_SYNC_BEFORE_LISTEN=false
```

Но для требования «при первом запуске сразу видеть все АЗС» оставляйте значение по умолчанию.
