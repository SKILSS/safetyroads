# Готово: АЗС только России

В архиве уже настроены:

1. Полный импорт российских АЗС через OSM/Overpass.
2. Только `country_code=RU` в публичном API.
3. Первый запуск с пустой БД — импорт АЗС до `listen`.
4. После первого запуска — кэш PostgreSQL, поэтому сайт открывается сразу.
5. Полная выдача российских АЗС на стартовом масштабе карты.
6. Цены из Интернета — не чаще одного раза в 24 часа.
7. При наличии точного price API — точные цены; без него — интернет-ориентиры с явной маркировкой.
8. Иностранные станции не вставляются через price provider.

Перед запуском укажи `DATABASE_URL`.
