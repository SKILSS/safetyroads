# АЗС России: кэш + обновление раз в 24 часа

В этой версии SafetyRoad карта не ждёт импорт АЗС при запуске.

- Сервер запускается сразу.
- Таблица `gas_stations` хранит кэш координат АЗС России.
- Фоновый синхронизатор запускается после старта сервера и затем проверяется каждый час, но фактический импорт выполняется не чаще одного раза в 24 часа.
- Источник координат: OpenStreetMap/Overpass, только внутри границы `ISO3166-1=RU`.
- При полном успешном обновлении старые OSM-станции, исчезнувшие из источника, удаляются. Если часть тайлов Overpass не ответила, старые данные сохраняются, чтобы не потерять станции из-за временного сбоя.
- Цены не перезаписываются синхронизацией координат.
- На масштабе РФ API отдаёт кэш российских станций; Leaflet MarkerCluster рисует их пакетами, чтобы интерфейс не зависал.

## Первый запуск

Если база пустая, первая синхронизация выполняется в фоне. Поэтому карта открывается сразу, а станции появятся после завершения импорта. Повторять `npm run sync-stations-russia` вручную не требуется.

## Ограничение источника

Под «все АЗС» здесь понимаются все станции, которые на момент синхронизации представлены в OpenStreetMap как `amenity=fuel`. OSM не гарантирует наличие абсолютно каждой коммерческой АЗС России.
